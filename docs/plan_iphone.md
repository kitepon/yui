# 結 iPhone アプリの現在地

iPhone・iPad版は[日本のApp Store](https://apps.apple.com/jp/app/id6816410748)へ一般公開を開始した。Mac版も2026年10月10日に同じアプリ登録で手動公開した。公開ページの反映と実機確認は[iPhone・iPad版](apple-platform-release.md#iphoneipad版の一般公開)と[Mac版](apple-platform-release.md#mac版の一般公開)の配布記録を参照する。

## Web との機能照合

| Web の面 | iPhone の実装 |
| --- | --- |
| Google／Apple／メールでログイン | GoogleとAppleはiOS標準の認証画面、メールは専用フォーム。セッションはKeychainに保存。 |
| 家、場所別一覧、機器操作 | 気温・湿度・照度、全場面、場所の選択、登録順の機器一覧、LAN 状態、照明・エアコン・カーテン・鍵などの操作。 |
| 場所 | 追加・改名・削除、部屋と機器の並べ替え、機器の移動。 |
| 場面 | 実行、追加・編集・削除・並べ替え。電源・明るさ・開き・エアコンの運転と設定値を編集。 |
| オートメーション | 時刻・機器・場面・センサーの条件、毎日・間隔・曜日、範囲条件、複数の機器操作、連続操作の省略、下位判定の打ち切り、実行・有効切替・編集・削除・優先順の変更。 |
| 機器グループ | iPhone・iPad・Macの場面画面で一覧・作成・編集・削除、機器の選択と停止時間（1〜1440分）、停止期限と待機中の操作を表示。個別の保存口（`group-save`・`group-remove`）を使う。判定と操作の記録はサーバーが持つ。本番利用にはサーバーの機器グループ対応が必要。 |
| 分析 | 24時間・7日・14日、数値の複数選択、機器の入切、オートメーションの実行印、時間・縦軸の拡大、全件の操作履歴。 |
| 接続 | アカウント、削除、接続コード、契約状態、StoreKitでの購入・復元、Nature Remo・SwitchBot・Smart Life、データセンター、Smart Life LAN 診断、所有者のダイキン・オーデリック、ヘルプ。 |

画面の意匠は iPhone 向けに作り直した。Web の写真付きホームヘッダーや PWA の追加案内は移植していない。Web の「デモ宅に戻す」は家の状態を置き換える操作のため、実機と同じ家を扱う iPhone 版にはまだ置いていない。

## 分析のフリーズと確認

最初の分析画面は、グラフの各点を作るたびに 1,440 件の日時を再変換していた。24時間のデータで数百万回の変換になり、実機で画面が止まった。日時変換を系列全体で共有し、各系列を高低差を残して最大120点へ整理した。25系列・計36,000点の再現データでは、変換は1,440回、描画点は計3,000点、準備は0.12秒だった。実機で最初の修正版が表示・操作できたことをオーナーが確認した。全項目を戻した版の実機確認は続行中。

## 実機と配備

- iPhone(Kaito) で Google ログイン、既存の家の表示、家電操作をオーナーが確認した。
- 更新版 `2e465b9` を本番へ配備し、公開 URL が 200、未ログイン時の家・分析・契約 API が 401 を返すことを確認した。iPhone(Kaito) への上書き導入と起動要求も成功した。
- 場所・場面・オートメーション・接続の拡張はシミュレータと実機向けのビルド、focused test を通した。更新後の画面操作と実データを使った機能照合はオーナーの実機確認待ち。

## 公開前の作業

- Sign in with Apple、アカウント削除、初回無料体験の表示を実装した。App Store ConnectへiPhone版1.0のビルド3、サブスクリプショングループ、月額、年額を同じ提出として送信し、4項目とも「審査待ち」になった。承認後は手動でリリースする。
- 月額・年額の商品、日本の価格、両プランの初回1か月無料、Appleの鍵、Server Notifications V2、アプリの画面写真を登録した。購入・通知・復元の実課金試験と審査中・公開後の作業は`docs/apple-billing-setup.md`に記録する。
- StoreKitが例外終了した時にApple購入予約が残る欠陥を修正し、例外直後に再度予約できることをシミュレーターと本番APIで確認した。iOS 26.5シミュレーターではSandbox Apple Accountの保存に失敗するため、購入確定はTestFlightを導入した実機で確認する。
- Web のデモ宅への切替は iPhone 版には未実装。

## 認証の実装境界

`ASWebAuthenticationSession` が結の Google ログインを開く。サーバーが Better Auth の
Google コールバックを受けた後、短命の引換コードをアプリへ返す。アプリが生成した
PKCE verifier を使った引換が成功した場合だけ、Better Auth のセッションを返す。
引換コードは一回限りで、5 分後に失効する。サーバー再起動中のログインは失敗を表示し、
利用者がやり直す。
