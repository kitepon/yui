# 結 iPhone アプリの現在地

## 実装した範囲

- SwiftUI のホーム画面、部屋別機器一覧、機器の操作画面、場面の実行、分析、接続設定。
- 機器名と場所の変更、部屋の追加・改名・削除、簡単なオン・オフ場面の作成・削除、オートメーションの有効切替。
- Google とメール＋パスワードのログイン。Google は既存の結アカウントを使い、セッションを Keychain に保管する。
- 既存の結サーバーと家のデータを共用。家電トークンの平文は API 応答に載せない。

## 実機確認

- iPhone(Kaito) へ開発用ビルドを導入し、Google ログイン、既存の家の表示、家電操作をオーナーが確認した。
- 公開 URL、未ログイン時の認可、Google 認証開始、無効な引換コードの拒否を配備後に確認した。

## 公開前の作業
- Web の場面編集とオートメーション編集の全条件・全操作は、現時点で iPhone から編集できない。Web で作成した設定の閲覧・実行・有効切替はできる。
- 課金状態の表示、契約管理、Sign in with Apple、App Store 提出は未実装。

## 認証の実装境界

`ASWebAuthenticationSession` が結の Google ログインを開く。サーバーが Better Auth の
Google コールバックを受けた後、短命の引換コードをアプリへ返す。アプリが生成した
PKCE verifier を使った引換が成功した場合だけ、Better Auth のセッションを返す。
引換コードは一回限りで、5 分後に失効する。サーバー再起動中のログインは失敗を表示し、
利用者がやり直す。
