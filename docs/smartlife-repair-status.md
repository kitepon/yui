# Smart Life修理の現在地

## 完了した範囲

2026年10月4日、修理コミット`032b3ed`をmainへpushし、既定ブランチへの包含を確認して本番へ配備した。

- LANスイッチの入／切を、操作前の再接続を省いて同一接続で操作・実状態確認する。
- 受領応答、状態通知、読取応答と3.1形式を扱う。
- 機器単位の保存と操作の直列化で、古い操作・読取結果によるONへの戻りを防ぐ。
- AlexaのLAN状態照会を実読取にし、応答時刻を実読取時刻にする。
- WebとiPhoneが保存済みの家を表示中に自動取得する。機器への毎分のポーリングは維持する。

lint、型検査、Nodeの285試験、開発ビルドが成功した。iPhoneの関連10試験はApple標準コマンドで成功。公開Alexa APIでテレビのOFFが260ms、ONが182ms、別のWeb確認ではOFFが157ms・画面反映が780msで成功した。元のONへ復元した。詳細は[実測と修理記録](../rag/tuya-lan-state.md)を参照。

iPhoneの1.0（6）はAppleの検証とアップロードが成功し、内部TestFlightの`IN_BETA_TESTING`を確認した。App Storeの一般公開版は変更していない。
